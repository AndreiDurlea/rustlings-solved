# More Functions

Now that you know about `if` and loops, it's time to go deeper into functions:

- **Recursion**: a function that calls itself (and needs a base case to stop).
- **Early return** with the `return` keyword.
- **Mutable references** (`&mut`) that let a function change a variable of its caller.
- **Function pointers** (`fn(i32) -> i32`): passing a function as an argument to another function.
