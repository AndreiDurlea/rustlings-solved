# Struct Basics

Structs let you group related values under one name. Each value is a named *field*.
There are also tuple structs whose fields are accessed by position (`.0`, `.1`, …).

In this section, structs are only used as data: they are created, passed to free functions,
changed through `&mut` references and destructured with patterns.
You will learn how to attach methods to them in the `structs` section later.
